# skill-map-designer

`tv1e-0009` - skill Claude Code du catalogue tv1e (tuveuxun.expert/skills). Gratuit, licence MIT.

## Installation

Copier le dossier dans `~/.claude/skills/map-designer/` (ou `.claude/skills/map-designer/` d'un projet), en gardant le fichier `SKILL.md` a la racine du dossier.

Le skill s'active tout seul quand la demande correspond a sa description (premier bloc de `SKILL.md`).
